# Font notices for the bundled Verovio 6.3.0 runtime

The unmodified Verovio Python wheel bundled with VArpeggio contains the
following music and text fonts as WOFF2 data embedded in its CSS files. The
font payloads retain their upstream copyright and license metadata. Verovio's
font inventory identifies every included font as SIL Open Font License 1.1
software. The complete OFL-1.1 text accompanies this notice in
`OFL-1.1.txt`.

- **Bravura** — designed by Daniel Spreadbury for Steinberg Media
  Technologies GmbH. "Bravura" is a Reserved Font Name.
  Source: <https://github.com/steinbergmedia/bravura>
- **Gootville** — designed by Grzegorz Pruchniakowski and distributed with
  MuseScore. Source inventory:
  <https://github.com/rism-digital/verovio/tree/version-6.3.0/fonts/Gootville>
- **Leipzig** — Copyright (c) 2014 Etienne Darbellay, Jean-Francois Marti and
  Laurent Pugin. "Leipzig" is a Reserved Font Name.
  Source: <https://github.com/rism-digital/leipzig>
- **Leland** — Copyright (c) MuseScore BVBA. "Leland" is a Reserved Font
  Name. Source: <https://github.com/MuseScoreFonts/Leland>
- **Petaluma** — designed by Steinberg Media Technologies GmbH. "Petaluma"
  is a Reserved Font Name.
  Source: <https://github.com/steinbergmedia/petaluma>
- **Liberation** — digitized data Copyright (c) 2010 Google Corporation,
  with Reserved Font Names "Arimo", "Tinos", and "Cousine"; Copyright (c)
  2012 Red Hat, Inc., with Reserved Font Name "Liberation".
  Source: <https://github.com/liberationfonts/liberation-fonts>

The matching Verovio source inventory and its statement that all included
fonts are OFL-1.1 licensed are available at:
<https://github.com/rism-digital/verovio/tree/version-6.3.0/fonts>

These fonts are distributed only as part of the Verovio/VArpeggio software
bundle, not as standalone products. VArpeggio does not modify their names or
font payloads.
